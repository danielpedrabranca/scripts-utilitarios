# scripts-utilitarios

Coleção de scripts utilitários de administração e automação, simples e sem dependências de terceiros, compartilhados com a comunidade.

## Scripts disponíveis

| Script | Sistema | O que faz |
|--------|---------|-----------|
| [volume-logon](windows/volume-logon) | Windows 10/11 | Define o volume em um percentual fixo ao fazer logon (útil quando o volume sempre inicia em 100%, como em VMs Hyper-V) |

## Como usar

Cada script fica em uma pasta própria, com README, instruções de instalação, compatibilidade e limitações. Para baixar tudo:

```bash
git clone https://github.com/danielpedrabranca/scripts-utilitarios.git
```

Ou, sem usar git, clique em **Code → Download ZIP** nesta página.

## Aviso

Os scripts são fornecidos "como estão", sem garantia. Leia o código e teste em um ambiente seguro antes de usar em produção.
